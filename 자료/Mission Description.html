DAY 2 MISSION DESCRIPTION

일정관리 Desktop App 만들기

다양한 입력자료로부터 차종 게이트 이벤트 일정을 추출하고,

🎯 Mission Goal

기능안전검증팀은 차종별 Gate / P2 이벤트 일정을 관리하고, 이를 기반으로 월별 준비 일정 확인 및 JIRA 점검 티켓 조회를 수행해야 합니다.


본 미션은 다양한 입력자료에서 일정 정보를 추출하고, 확인/수정 후 Confluence에 반영하며 차종별 타임라인과 JIRA 연계를 지원하는 실행 가능한 Desktop App을 구현하는 것이 목표입니다.

📋 Scenario

관련 일정 정보는 이메일(아웃룩 드래그), PDF, 이미지, 텍스트, 엑셀 등 다양한 형식으로 전달될 수 있습니다.


사용자는 입력자료에서 추출된 일정 후보를 검토한 뒤, Confluence 기반 저장소에 반영하고 차종별 타임라인 및 월별 이벤트 화면에서 관리할 수 있어야 합니다.

📥 Required Inputs
📧 이메일 메시지 (아웃룩 드래그) 📄 PDF 🖼 그림파일 (JPG / PNG) 📝 텍스트 선택 & 드래그 📊 엑셀 파일
💡 App 내에는 위 자료를 받을 수 있는 Drag & Drop Zone이 포함되어야 합니다.
🛠 Allowed Tools / Tech
H-CHAT Claude Code Codex Co-Pilot 그 외 사내 AI 도구

구현 언어 및 기술 스택에는 제한이 없습니다.

✅ Core Functional Requirements
1
일정 정보 추출
입력자료로부터 차종, 이벤트 (GATE-3 / GATE-4 / GATE-5 / P2 / LP2 등), 담당자 및 일정 정보를 추출할 수 있어야 합니다.
2
일정 추출 후보 관리
입력자료별로 일정 추출 후보를 확인/수정할 수 있어야 하며, 후보는 차종 / 이벤트 / 담당 + 복수 일정 항목 구조로 다룰 수 있어야 합니다.
3
Confluence 반영
확정된 일정은 Confluence 공유 페이지를 기준 저장소처럼 활용하여 반영할 수 있어야 합니다.
※ 대상: hmg.atlassian.net/wiki/spaces/RND/pages/604243425/ 하위 그룹별 페이지 (Page ID 고정)
4
차종 게이트 이벤트 타임라인
차종별 1라인 형태의 타임라인으로 표현되어야 하며, 화면에는 최소 2개월 수준의 기간 흐름을 확인할 수 있어야 합니다.
◀ 2026-07 ▶ 이동 버튼으로 기간 이동 가능. 차종 클릭 시 우측 JIRA 조회와 연동.
5
월별 이벤트 조회 및 JIRA 연계 (Project: ADE)
월 이동 버튼에 따라 해당 월의 이벤트 목록이 조회되며, 특정 차종 선택 시 ADE 프로젝트의 관련 JIRA 목록 조회 및 티켓 상세보기가 가능해야 합니다.
상세보기에서 각 필드 속성 (Key, 단계, 점검유형, 시스템, 상태, 담당자 등) 조회 및 파일 Drag & Drop 첨부를 지원해야 합니다.
⚠ 저장 기능 제한 안내 (UI 표시 문구) 저장 기능은 현재 제한됩니다. 연결된 JIRA는 운영(Live) 서버로, 실제 데이터의 추가·수정·삭제 기능은 구현할 수 있으나 테스트 및 실제 호출은 허용되지 않습니다.
티켓 조회 화면은 실제 웹 브라우저 티켓보기와 속성 및 형식이 일치해야 하며, 조회 화면에서 사용자 입력은 허용하나 실제 저장 버튼은 Disable 되어야 합니다.
6

🗄 Data / Storage Notes
